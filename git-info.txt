Базовые команды git
	git init - создать новый репозиторий
	git status - показать статус файлов
	git add - добавить файлы (отметить строки для сохранения)
	git commit - сохранить изменения 
	git log - показать историю
	git diff - показать отличия (что изменилось с прошлого раза)

git commit и его флаги
	git commit - создать новое сохранение
	git commit -m "<сообщение>" - флаг для сообщении (часто кратко описывают что изменилось)
		--amend - позволит дополнить или изменить последний commit
	git commit -a - добавляет все измененные и удаленные файлы в коммит
	git commit --allow- empty - создать коммит без изменений

git diff - покажет что изменилось с последнего коммита
	+++ - добавленный строки
	--- - удаленные

Дополнительные команды
	git log --oneline - быстро посмотреть историю (кратко)
	git diff --staged - что в staging area
	git restore file - отменить изменения в файле
	git branch -r - посмотреть удаленный ветки
	git rm --cached file - перестать отслеживать файл 


Команды создания переключения веток git
	git branch soski - создаст ветку soski
	git checkout soski - переключиться на ветку soski
	git checkout -b soski - создать и сразу переключиться в ветку soski
	git branch -d soski - удалить ветку soski (тк после слияния ветка не нужна)
	git branch -M piski - переиминовать текущую ветку в piski


Из интересного ветки именнуют напрример feature/readme-update - слеш здесь не знаачит файл внутри ветки feature а это именно полное название, так делают для большей информативности, первое слово это группа разработки (feature, bugfix, hotfix) а второе конкретная задача в данной ветке (readme-update, new-button и тд)


Слияние веток - чтобы слить ветку в например в мастер нам нужно сначало перейти в мастер и ввести команду слияние
	git merge <имя-ветки-которую-вливаем>
	

Самая крутая команда в гит
	git remote add origin <url-github> - команда буквально значит щас будем подключаться к удал. репозиторию


Вообще дальше гениальная тема идет, ветку меин можно запушить в ветку меин на гитхабе так что она навсегда запомнит куда меину пушиться на гит хаб и так разотает с каждой веткой
	git push -u origin main - закрепит связь локального меин с меин гитхаба
	git branch -vv - покажет все связи веток 
	git pull - забрать все новые изменения в удаленном реп. к себе
